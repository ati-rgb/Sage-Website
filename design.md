# The SAGE Blueprint - Design Style Guide - Updated Branding

## Design Philosophy

### Visual Language
**Sophisticated Residential Aesthetic**: Clean, modern design that evokes high-end residential interiors rather than clinical or institutional spaces. The design should feel like stepping into a beautifully designed home that happens to be perfectly accessible.

**Warm Professionalism**: Balancing credibility and expertise with approachability and warmth. The visual language should inspire confidence while remaining inviting to both homeowners and design professionals.

**Empowerment Through Beauty**: Every design choice reinforces the message that accessibility and safety can be stunningly beautiful, never compromising style for function.

## Color Palette - Updated with SAGE Blueprint Branding

### Primary Colors
- **SAGE Dark** (#2B3210): Primary brand color, deep sophisticated green
- **SAGE Medium** (#505631): Secondary green, natural and calming
- **Warm White** (#FFFFFF): Clean backgrounds, maximum readability
- **SAGE Cream** (#E5E2D9): Secondary backgrounds, warmth

### Accent Colors
- **SAGE Orange** (#DE6E27): Highlights, CTAs, energetic accent
- **SAGE Dark** (#2B3210): Primary text, strong contrast

### Accessibility Compliance
All color combinations maintain minimum 4.5:1 contrast ratio for WCAG AA compliance.

## Typography - Updated with SAGE Blueprint Fonts

### Primary Typeface: Tangkiwood
- **Usage**: Headlines, hero text, section titles
- **Characteristics**: Elegant serif with strong presence, editorial quality
- **Weights**: Regular, Medium, Bold

### Script Typeface: The Something Script
- **Usage**: Logo, special headings, decorative elements
- **Characteristics**: Handwritten elegance, personal touch
- **Usage**: Sparingly for maximum impact

### Secondary Typeface: Arial
- **Usage**: Body text, navigation, UI elements
- **Characteristics**: Clean, highly legible sans-serif
- **Weights**: Light, Regular, Medium, Bold

### Hierarchy
- **H1**: Tangkiwood Bold, 48px, SAGE Dark
- **H2**: Tangkiwood Medium, 36px, SAGE Medium
- **H3**: Arial Medium, 24px, SAGE Medium
- **Body**: Arial Regular, 16px, SAGE Dark
- **Small Text**: Arial Light, 14px, SAGE Dark

## Visual Effects & Animation

### Background Effects
- **Subtle Gradient Flow**: Soft sage-to-cream gradients for hero sections
- **Organic Shapes**: Gentle curved overlays in muted tones
- **Texture Overlays**: Subtle linen or paper textures for depth

### Interactive Animations
- **Smooth Transitions**: 300ms ease-in-out for all interactions
- **Hover Effects**: 
  - Cards lift with soft shadow expansion
  - Buttons shift color with gentle glow
  - Images scale slightly (1.02x) with overlay fade-in
- **Scroll Animations**: Gentle fade-up effects, 16px vertical movement

### Visual Hierarchy
- **Depth Through Shadows**: Subtle drop shadows for card elevation
- **Color Progression**: Sage green for primary actions, muted gold for secondary
- **White Space**: Generous padding and margins for breathing room

## Layout & Composition

### Grid System
- **Desktop**: 12-column grid, 1200px max width
- **Tablet**: 8-column grid, responsive breakpoints
- **Mobile**: Single column, full-width content

### Section Structure
- **Hero Sections**: Full-width with centered content, generous vertical padding
- **Content Blocks**: Alternating layouts, consistent 80px vertical spacing
- **Card Layouts**: 3-column grid on desktop, stack on mobile
- **Image Treatments**: Rounded corners (8px), consistent aspect ratios

## Component Design

### Buttons
- **Primary**: Sage green background, white text, 12px border radius
- **Secondary**: White background, sage green border and text
- **Hover States**: Subtle color shifts, no dramatic changes

### Cards
- **Background**: White with subtle shadow
- **Border Radius**: 12px for modern feel
- **Padding**: 24px internal spacing
- **Hover**: Lift effect with shadow expansion

### Forms
- **Input Fields**: Clean borders, focus states in sage green
- **Labels**: Suisse Medium, positioned above fields
- **Validation**: Gentle error states in warm red tones

## Imagery Guidelines

### Photography Style
- **Lighting**: Natural, warm lighting that feels inviting
- **Composition**: Clean, uncluttered interiors showcasing both beauty and accessibility
- **Color Treatment**: Slightly warm color grading to match brand palette
- **Subject Matter**: Beautiful homes with subtle accessibility features

### Iconography
- **Style**: Minimal line icons, consistent stroke weight
- **Color**: Sage green or charcoal depending on context
- **Size**: 24px standard, scalable for different uses

## Responsive Design

### Breakpoints
- **Mobile**: 320px - 767px
- **Tablet**: 768px - 1023px
- **Desktop**: 1024px+

### Mobile Considerations
- **Typography**: Larger base font size (18px) for readability
- **Touch Targets**: Minimum 44px for all interactive elements
- **Navigation**: Collapsible menu with clear hierarchy

## Brand Applications

### Logo Treatment
- **Primary**: Sage green text on white background
- **Reversed**: White text on sage green background
- **Minimum Size**: 120px width for legibility

### Certification Badges
- **SAGE Certified**: Circular badge with sage green background
- **Master Sage**: Enhanced badge with gold accents
- **Usage**: Always maintain clear space around badges

This design system creates a cohesive, professional aesthetic that positions The Sage Blueprint as the premium authority in beautiful aging in place design while remaining accessible and welcoming to all users.
